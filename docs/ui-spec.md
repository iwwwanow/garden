# UI Specification — Garden of the Goddess of Flowers

> Логика игры: `docs/game-logic.md` | Роуты и архитектура: `docs/planning.md`

---

## Design System

**Стиль:** flat, без скруглений, минималистичный — почти ASCII/деревянный  
**Шрифт:** Inter  
**Иконки:** Unicode/ASCII-символы (без icon-библиотек), конкретные символы согласуются с дизайнером  
**Цвета:**

| Роль | Hex |
|------|-----|
| Фон | `#ffffff` |
| Nav bar | `#d9d9d9` |
| Кнопка primary (action) | `#243c9a` |
| Кнопка confirm (вода/посев) | `#249a57` |
| Текст | `#000000` |
| Карточки / плашки | `#ebebeb` |
| Активный цветок (highlight) | `#2cff76` outline |

## Страницы

---

### 1. Home / Сад (`/home` — свой, `/garden/[id]` — чужой)

Главный экран. При просмотре чужого сада (`/garden/[id]`) — те же блоки, кнопки редактирования скрыты.

#### Hero (100vh)

- Имя пользователя (крупно)
- Баланс FD — **самая крупная цифра** в хэдере
- Вторичные метрики (мелко): `120 дней роста`, `2548 поливов`
- Иконка-кнопка [PE] — редактировать профиль (только свой сад)
- Активный цветок — большое изображение по центру
  - На изображении снизу: сумма FD (заработано цветком всего)
  - Кнопка [P] — Полить (если сегодня ещё не поливал)
  - **Выбор цветка для hero:** показывается цветок с максимальным `day` (= самый долгорастущий). Total FD цветка = `day*(day+1)/2` — монотонно растёт с `day`, хранить отдельно не нужно. Клиент сортирует результат `GET /api/flowers/user/:id` по `day DESC`, берёт первый.
- **[Посадить цветок]** — зелёная кнопка, внизу hero, всегда видна без скролла

> При просмотре чужого сада (`/garden/[id]`): вместо [PE] — аннотация `owner: @username` (ссылка на профиль). Кнопка "Посадить" скрыта.

#### Seeds preview

- Заголовок: `семена`
- 3 карточки (FlowerCard, type=seed) в строку или 2-column сетку
- Ссылка **Смотреть все →** → `/seeds`

#### Herbarium preview

- Заголовок: `гербарий`
- 3 карточки (FlowerCard, type=herbarium)
- Ссылка **Смотреть все →** → `/herbarium`

---

### 2. Seeds — Все семена (`/seeds`)

Полный инвентарь семян текущего пользователя.

**Layout:** 2-column card grid (FlowerCard, type=seed), скролл  
**Empty state:** "У вас пока нет семян" + текст о том, как получить (каждые 7 дней с живого цветка)

---

### 3. Seed Detail — Семя (`/seeds/[id]`)

**Layout:**
- Большое изображение (336×446, или aspect-ratio 336/446)
- Badge [S] сверху-слева на изображении
- Кнопки:
  - **[Посадить цветок]** — зелёная — засевает семя как новый цветок
  - **[Поделиться]** — синяя — передать семя другому пользователю
- Блок описания (серый фон) — флейвор-текст / лор
- Мета: `Приобретено: DD.MM.YYYY`, `От: @username`

---

### 4. Flower Detail — Живой цветок (`/flower/[id]`)

Детальная страница активного (живого) цветка.

**Аннотация:** `owner: @username` — ссылка на `/garden/[id]`

**Layout:**
- Большое изображение
- Badge типа цветка (иконка цветка) — сверху-слева
- `10 FD` — внизу изображения (сколько заработано цветком за всё время)
- Кнопки (доступны **всем пользователям**, включая владельца):
  - **[Полить]** — зелёная — полить цветок (раз в день на пользователя)
  - **[Запросить полив]** — синяя — уведомить других о необходимости полива
- Стата: `Посажен: DD.MM.YYYY`, `Принес за все время: XXXX FD`

> Полив доступен всем — и владельцу, и гостям. "Запросить полив" отправляет уведомление/запрос (механика нотификаций уже в API).

---

### 5. Herbarium — Гербарий (`/herbarium`)

Коллекция мёртвых цветков пользователя.

**Layout:**

#### Витрина (публичная)
- Крупное изображение последнего/избранного цветка вверху
- Badge [H] сверху-слева на изображении
- 2-column card grid (FlowerCard, type=herbarium) — только публичные

#### Скрытые
- Разделитель с лейблом `Скрытые`
- Те же карточки — цветки, которые пользователь скрыл из витрины
- **Видны только владельцу.** При просмотре чужого гербария (`/garden/[id]` → herbarium preview) скрытые не показываются.

**Empty state:** "Ваш гербарий пуст — здесь будут жить воспоминания о цветках"

---

### 6. Herbarium Flower — Мёртвый цветок (`/herbarium/[id]`)

**Layout:**
- Большое изображение
- Badge [H] сверху-слева
- Кнопка (toggle):
  - Если скрыт: **[Выставить]** — синяя — добавить в публичную витрину
  - Если выставлен: **[Скрыть]** — серая — убрать из витрины
- Стата:
  - `Принес за все время: XXXX FD`
  - `Посажен: DD.MM.YYYY`
  - `Умер: DD.MM.YYYY`

---

### 7. Leaderboard — Рейтинг (`/leaderboard`)

**Табы:** `FD` | `Дней подряд` | `Семена`

> Таб "Поливы" (Верда) — **в бэклоге**, не реализуется сейчас.

**Layout per tab:**
- Список строк: `[rank] [avatar] [username]   [score]`
- Строка текущего пользователя **выделена** (sticky снизу, если вне viewport)
- SSR — страница кешируется, SEO-доступна

---

### 8. Profile (`/profile`)

- Username, FD-баланс
- Кнопка редактировать имя [PE]
- (Детали wireframe не финализированы)

---

### 9. Auth (`/auth`)

- Форма: логин / регистрация (переключение)
- SSR

### 10. Notifications (`/notifications`)

- Лента событий: кто полил, умер цветок, получено семя
- Кнопка "Отметить все прочитанными"
- CSR, за авторизацией

## Компоненты

---

### FlowerCard

Используется в: garden preview, seeds grid, herbarium grid

```
┌───────────────────┐
│ [type-icon]       │  ← иконка типа: S / H / (цветок) — сверху-слева
│                   │
│    [image]        │
│                   │
│ 10 FD    [P/Z]   │  ← FD снизу-слева, статус-иконка снизу-справа
└───────────────────┘
```

**Варианты (type):**

| type | type-icon | Статус снизу-справа |
|------|-----------|---------------------|
| `flower` | иконка цветка | [P] если нуждается в поливе |
| `seed` | [S] | нет |
| `herbarium` | [H] | нет |

**Размеры:** ~149×230px (карточка в 2-column grid, контейнер 402px)

---

### ActionButton

| variant | Цвет | Применение |
|---------|------|-----------|
| `primary` | `#243c9a` | Поделиться, Запросить полив, Выставить |
| `confirm` | `#249a57` | Посадить цветок, Полить |
| `muted` | `#c0c0c0` / `#d3d3d3` | Скрыть, неактивные действия |

Ширина: `363px` (при контейнере 402px — отступы по 19-20px с каждой стороны)  
Высота: `55px`  
Текст: 24px Inter 400, белый

---

### BottomNav

- Фиксированный внизу, высота `101px`, фон `#d9d9d9`
- 3 таба: Сад / Рейтинг / Профиль
- Каждый таб: Unicode-иконка + текстовый лейбл
- Активный таб — визуально выделен (цвет или подчёркивание)

---

### HeroBanner

- Высота `100vh`
- Хэдер: username (24px) + FD-баланс (крупно, приоритет) + мелкие метрики
- Изображение цветка — центр, большое
- FD-сумма поверх изображения снизу
- CTA [Посадить цветок] — зелёный, в нижней части hero

---

[rank]  [avatar]  [username]   [score]
