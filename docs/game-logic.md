# Game Logic — Garden of the Goddess of Flowers

## Концепция

Web-app + Telegram Mini App. Пользователь выращивает виртуальный цветок, поливая его раз в сутки.
Цветок растёт бесконечно и приносит валюту — **Flowering Days (FD)**.
Пересохший цветок попадает в гербарий. Каждые 7 дней цветок даёт +1 семя.

## Правила полива

- Каждый цветок можно полить **ровно один раз в день** — кем бы то ни было.  
  Как только цветок полит (любым пользователем), он считается политым на этот день.
- Один пользователь может поливать сколько угодно **разных** цветков в день — свои и чужие.
- Для прогресса роста достаточно **одного полива от любого пользователя**.

---

## Прогресс и начисление FD

Ежедневный тик (полночь):

1. Для каждого активного цветка: **был ли хоть один полив вчера?**
2. Если нет → цветок **пересыхает** (`is_dried = true`).
3. Если да:
   - Начислить FD владельцу за прожитый день.
   - `day += 1`
   - Если `day % 7 == 0` → выдать **+1 семя**.

### Формула FD — линейная

```
FD(day) = day
```

| День | FD за день | Накоплено  |
|------|-----------|------------|
| 1    | 1         | 1          |
| 2    | 2         | 3          |
| 3    | 3         | 6          |
| 7    | 7         | 28         |
| 14   | 14        | 105        |
| N    | N         | N*(N+1)/2  |

Цветок растёт и приносит FD **бесконечно**.

---

## Семена

Каждые 7 дней цветок даёт **+1 семя**.

Семена можно:
- Поделиться с другим пользователем
- Посадить (вырастить новый цветок)

---

## Несколько цветков

Можно выращивать до **64 цветков** одновременно.

---

## Гербарий

Пересохшие цветки — неактивны, нельзя оживить.
Отображаются в обычном цвете с лейблом «пересох».

---

## Уведомления

Отдельная вкладка **Notifications** в интерфейсе.

События:
- Кто-то полил твой цветок
- Тебе поделились семенами
- Цветок пересох
- Цветок дал семена (каждые 7 дней)

## API (Go REST, реализован)

| Метод | Путь                        | Описание                               |
|-------|-----------------------------|----------------------------------------|
| POST  | /api/auth/register          | Регистрация (login + password)         |
| POST  | /api/auth/login             | Вход, возвращает JWT                   |
| GET   | /api/me                     | Текущий пользователь + цветки + семена |

| GET   | /api/flowers                | Список шаблонов цветков сезона         |
| GET   | /api/flowers/:id            | Шаблон цветка по ID                    |
| POST  | /api/flowers/plant          | Посадить новый цветок из семян         |
| POST  | /api/flowers/:id/water      | Полить цветок (свой или чужой)         |
| GET   | /api/flowers/user/:id       | Цветки пользователя                    |
| GET   | /api/leaderboard            | Топ по FD балансу (`?limit=&offset=`)  |
| GET   | /api/seeds                  | Свои семена                            |
| POST  | /api/seeds/share            | Поделиться семенами                    |
| GET   | /api/notifications          | Список уведомлений                     |
| PATCH | /api/notifications/read     | Отметить все прочитанными              |
| GET   | /api/users/:id              | Публичный профиль пользователя         |
